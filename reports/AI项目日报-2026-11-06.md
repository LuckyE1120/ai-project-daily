## 体验路径与限制

### Mika：先核对手机与模型条件

从[官方 Releases](https://github.com/wangzan101/Mika/releases)下载 APK，按[官方入门说明](https://github.com/wangzan101/Mika#get-started-in-three-steps)配置模型，再按手机控制向导配对无线调试。只体验聊天、网页和文件时可跳过手机控制；Linux 沙箱需 arm64 设备。

先用测试手机做一个容易核对的小任务，例如调整测试闹钟，再检查中断与接管。后台运行和机型适配需实际验证，演示不证明所有应用可用。[隐私说明](https://github.com/wangzan101/Mika#privacy--safety)明确没有 Mika 中转服务器，但对话和屏幕信息会发给所选模型提供方；端上运行不等于离线推理，模型成本另计。本期未安装 APK、授权调试或验证数据流。

### Agent Cockpit：从自带演示看证据失效

按[官方快速开始](https://github.com/chutingyean/Agent-Cockpit#quick-start)克隆后执行 `npm install`、`npm run demo`，再用 `node bin/cockpit.mjs serve --repo demo/research` 打开默认 `http://127.0.0.1:4180`。演示提供 break/restore 操作，适合观察依赖代码变化如何传到结论卡片。

[接入说明](https://github.com/chutingyean/Agent-Cockpit#use-it-on-your-own-research-repo)中的 init 会写入 MCP 配置、规则与 hooks，建议先在测试 Git 仓库体验。哈希变化检查和证据引用验证不能证明统计方法、数据或科学结论正确；检查引擎不调用 LLM，不代表驱动实验的 Agent 没有模型成本。本期未接入研究仓库，也未复现失效传播与回放效果。
