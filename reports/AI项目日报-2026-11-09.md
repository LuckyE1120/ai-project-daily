## 今日重点

本期新增关注 OpenMausBot 和 Vercel 的 agent-desktop。OpenMausBot 把多名本地 Agent、各自的工作电脑和聊天式协作放进一个开源桌面工作区；agent-desktop 则用操作系统辅助功能树让 Agent 查看并操作桌面应用，并在 11 月 5 日发布的 v1.2.0 中加入 MCP 服务入口。想体验桌面自动化，先看 agent-desktop；想比较多 Agent 的组织方式，可再看 OpenMausBot。本期核对了官方仓库和发布说明，未在本机安装或实测。首次收录不等于刚发布；只有注明版本日期的更新才作为近期版本事实。

## 体验路径与限制

### agent-desktop：先观察，再执行

官方 README 提供 `npm install -g agent-desktop`、`agent-desktop status` 和 `agent-desktop permissions --guide` 入口。最小体验可以用 `agent-desktop snapshot --app Finder -i` 查看可交互元素，然后对一个无风险元素执行 click，再 snapshot 验证。官方文档说明各操作通过当前快照里的引用定位；界面改变后应重新读取，避免使用过期引用。

v1.2.0 于 2026 年 11 月 5 日发布，Release Notes 列明增加 MCP stdio 服务、macOS 菜单与列表行支持、从 stdin 输入文本以及部分快照处理修复。MCP 启动入口为 `agent-desktop mcp`。软件本身不含模型，调用 Agent 负责规划；无障碍树也不一定暴露所有界面元素。截图、剪贴板、命令输出可能含私人信息，使用前应避免把这些内容写入公开日志。本期未配置 MCP 客户端，也未在 macOS 上验证权限流程。

### OpenMausBot：以权限边界明确的小任务开始

官方提供 macOS DMG、Windows 安装包及 Ubuntu 24.04 x64 的 beta 包。源码体验命令和前提见[官方 README](https://github.com/milind-soni/OpenMausBot#quick-start)：安装依赖后可启动本地 harness 和桌面界面；需要已登录的 `claude`、`codex` 或 `grok` CLI。它也提供有限的 stdio MCP 控制接口，可查看/配置 Bot、发送任务和中断运行。

官方说明本地会话和事件保存在 `~/.openmausbot`，本机控制功能需要显式开启；Ubuntu Wayland 主机控制目前关闭，Ubuntu 桌面能力仍为 Beta。自行填写的 API Key 以明文存于权限受限的本地 `config.json`，不适合直接放入共享账户或未经保护的环境。接入邮件、GitHub 等服务前，先检查授权范围和权限卡。当前 README/功能清单是官方现状信息，并不能证明每个 Agent 的执行准确率；本期没有配置账号、启动桌面程序或验证数据流。
