## 体验路径与限制

### Remotion：先完成短片导出

按[官方安装文档](https://www.remotion.dev/docs/)运行 `npx create-video@latest` 选择模板，再用 `npm run dev` 预览。文档还提供 Agent Skills 入口。先用固定文本、统一字体和简单转场制作短片，确认能导出后再增加时长与素材；这是建议任务，本期没有实际渲染。

系统条件以当前文档为准，旧教程可能不同。仓库明确提示采用[特殊许可](https://github.com/remotion-dev/remotion/blob/main/LICENSE.md)，部分公司使用情形需购买许可，不应直接理解为任意规模免费商用。它适合代码控制画面，实际创作效率仍需用自己的素材验证。

### GenOffice：检查文件往返编辑

从[官方下载入口](https://github.com/genspark-ai/genoffice#download)选择系统和架构，先在应用内修改一份测试文件，再决定是否连接编程 Agent。官方提供 Settings → Integrations 入口，也提供 `genoffice mcp`；本期没有更改本机客户端配置。

[官方仓库](https://github.com/genspark-ai/genoffice)标注 Apache-2.0，覆盖文档、表格、幻灯片等。文件本地保存不等于所有 AI 推理都在本地；模型调用取决于所选服务。建议核对修订、表格公式和导出排版，不能把作者的兼容性描述当成已验证结论。

### Firecrawl：区分托管与自部署

最短体验路径是[官方 Quick Start](https://github.com/firecrawl/firecrawl#quick-start)中的 Playground，准备 Key 后采集一个页面。CLI 或 MCP 是后续接入方式，先判断提取内容是否完整，再接入日报或其他 Agent 流程。托管调用需要核对账号额度与服务条款，本期未注册或消耗额度。

[自部署指南](https://docs.firecrawl.dev/contributing/self-host)使用 Docker Compose，并明确快速入门关闭 API 鉴权、没有完整生产配置，也不包含全部云端能力。仓库主体为 AGPL-3.0，SDK 等目录另有许可。采集失败、动态内容缺失和提取错误都需要用具体页面验证，不能保证任意站点都可用。
