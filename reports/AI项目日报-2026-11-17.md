## 体验路径与限制

### Craft Anything：先在获准检查的目标上验证“观察—构建—对照”

官方提供 Windows、macOS、Linux、FreeBSD 安装包；Mac 通用 DMG 已签名并公证。试做网站重建时，先在设置里选择编码 Agent，再对自己维护或获准检查的网站运行 `Study → Build → Check`，用三种视口的截图与页面检查记录核对结果。无需接触网站源代码的默认 Clean-room 模式适合作为起点；若打开 Deep 模式，工具可读取代码与文件。

项目处于 early alpha。官方称 Claude Code 的构建路径已实际验证；Codex adapter 存在，但还没有在真实安装上验证。Clean-room 是产品层的访问规则，不是操作系统沙箱；编码 Agent 仍会以其自身权限读写/运行本机内容。只对有权检查的目标使用，不让构建任务访问真实密钥或生产数据。本期未下载或实测。

### Jane Street Skill：低门槛试一个学习任务

仓库中的 `socratic-tutor/SKILL.md` 是可复用的自然语言工作流说明，不是独立模型或课程内容。按[Codex 官方安装目录说明](https://developers.openai.com/api/reference/cli)，将 Skill 文件夹放到用户级 `~/.agents/skills/` 可供多个项目使用，或放进项目级 `.agents/skills/`；开始新的 Codex 会话后显式启用它，再要求“用苏格拉底式方法教我一个主题”。

当前公开仓库实际只有一个 Skill。效果依赖模型遵循说明的程度，不能替代经过审核的教学材料或专业建议；星标增长也不代表教学质量经评估。本期未安装或试用。

### HA-MCP：先以只读方式确认权限边界

对已有 Home Assistant 的用户，官方推荐把 HA-MCP 集成为 HA 组件：HA 2026.8—2026.10 可从 HACS 安装；2026.11+ 可从 Marketplace 安装。重启 HA 后添加 HA-MCP Server 集成，选择客户端连接方式，再把连接 URL 配到 MCP 客户端。管理动作以 HA 管理员身份执行，令牌可跨设备使用，必须按密码保管；远程和局域网访问默认关闭。初次体验可先保持远程关闭，只连接可信客户端并测试查询状态，之后再考虑启用写操作。

官方 README 列出约 86 项工具，并指出支持工具搜索模式；对工具目录一次性注入较多、上下文有限的模型尤其有用。改动自动化、仪表盘或设备会产生实际影响，删除和文件/YAML 工具更敏感；后者为显式启用的可选能力。stdio 传输存在已知连接问题，正式接入优先使用集成或 HTTP 模式。本期未配置 Home Assistant、令牌或 MCP 客户端。
